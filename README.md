# 課堂專案－工作委託與接案管理平台

## 專案簡介
本專案以線上工作委託與接案流程為核心，建置一套串聯委託人與接案者的媒合與專案管理平台。委託人可發布案件、設定需求並管理專案進度；接案者則可瀏覽案件、提出報價與上傳提案內容。案件成立後，雙方可透過系統進行進度追蹤、成果繳交、問題回報與評價，將委託流程由案件發布延伸至合作結束。

## 系統特色
角色權限管理｜案件發布與瀏覽｜投標與提案｜專案狀態管理｜Issue 問題追蹤｜成果上傳｜雙向評價

## 我負責的範疇

### 主要系統功能開發
負責使用者註冊與登入、角色管理、案件建立與編輯、案件瀏覽、投標與提案、合作對象選擇、Issue 問題追蹤、成果繳交及雙向評價等主要功能。

### 後端與資料庫串接
使用 FastAPI 建置後端功能，並配合資料庫進行使用者、案件、提案、合作狀態與評價等資料的存取與管理。

### 頁面與系統流程整合
整合前後端功能與主要操作流程，使案件可由發布、提案、媒合、執行一路進行至結案與評價。

### 功能測試與問題修正
針對主要操作流程進行測試，並依實際使用情況調整功能邏輯與處理執行過程中出現的問題。

## 團隊分工補充
本專案為三人小組完成，其中限時競標與檔案版本控管功能由另一位組員負責；其餘主要系統功能與整合工作由我負責。
